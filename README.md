## 이 저장소는

[원작 长风 Long Wind](https://github.com/jbang2004/long-wind)를 한국어로 옮긴 포크입니다. 게임 내 메뉴·웨이브 안내·조작 안내·통계·로딩 문구를 한국어로 번역했고, 붓글씨 한자 글리프(斩·闪·格·气·劍 등)와 도장(印), 고전시 원문은 무협 특유의 분위기를 살려 원형 그대로 두고 한글 표기를 병기했습니다. 게임 엔진·로직·에셋은 원작 그대로입니다.

## 게임 소개

외로운 검객 하나, 세 개의 장(章). 순수 three.js / WebGL로 만들어져 설치 없이 웹페이지를 열면 바로 플레이할 수 있습니다.

| 장 | 무대 | 보스 |
|---|---|---|
| 1 · 장풍(長風) | 석양 역광의 황금 초원, 바람에 흔들리는 풀 파도, 외로운 나무와 석비 | 단도객(斷刀客) |
| 2 · 죽림야우(竹林夜雨) | 비 내리는 밤의 대숲, 번개, 물웅덩이 반영, 석등롱 | 야효(夜梟, 모습을 감추고 순간이동하는 자객) |
| 3 · 장가등화(長街燈火) | 강남 고진의 긴 거리, 오백 개의 등롱, 수로와 석교, 놀라 달아나는 시민 | 한산객(寒山客) · 무대 앞 결전 |

전투: 경·강 연속 베기, 막기와 적중 타이밍 패링, 무적 시간이 있는 회피, 자세 붕괴와 처형, 검기(劍氣), 띄우기·넘어뜨리기, 조준 고정, 궁수·방패병·창병·자객 등 다양한 적.

## 어떻게 만들어졌나

**사람은 코드를 쓰지 않았습니다.** 원작자는 중국어로 원하는 것을 설명하고, 플레이하고, 의견을 냈을 뿐이며 설계·코딩·디버깅·테스트·성능 최적화는 모두 Claude Code(Opus 5.5)가 수행했습니다. Opus 5.5가 총괄로서 지형·풀·하늘·캐릭터·전투·오디오·UI 등 여러 병렬 하위 에이전트에 작업을 나누고, 인터페이스 계약서([CONTRACTS.md](CONTRACTS.md))와 아트 바이블([docs/BIBLE.md](docs/BIBLE.md))로 통합했습니다.

## 기술 스택과 구조

- **렌더링**: three.js(유일한 런타임 의존성) + WebGL. 커스텀 후처리 파이프라인(TAA 업스케일링, 블룸, AO, 볼류메트릭, 합성 단계) — `src/core/`
- **월드**: 지형·풀·대나무·꽃·나무·고진·바위 전부 절차적 생성. 워커에서 지형 계산 — `src/world/`
- **게임플레이**: 전투(콤보·패링·자세), 적 AI, 디렉터(웨이브 연출), 카메라 — `src/game/`
- **오디오**: 악기(고금·효·당고) 합성, 절차적 작곡, 효과음·환경음·시장 소리 전부 WebAudio — `src/audio/`
- **UI**: 붓 획·먹 번짐·도장을 캔버스로 그려 텍스처화하는 자체 브러시 엔진 — `src/ui/brush.js`, HUD·화면 — `src/ui/`
- **레벨**: 장별 정의(배치·바이옴·날씨·웨이브) 데이터 모듈 — `src/levels/`
- **빌드**: Vite. `base: './'` 상대 경로로 빌드되어 GitHub Pages 하위 경로에서 그대로 동작

## 빌드와 실행

```bash
npm install      # 의존성 설치 (three.js + 개발용 vite/playwright-core)
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 정적 빌드
npm test         # 헤드리스 게임플레이 테스트 30종
npm run shot     # 헤드리스 스크린샷 (시스템 Chrome 필요, macOS 경로 기준)
```

URL 파라미터: `?level=steppe|bamboo|town` (장 선택), `?q=low|med|high` (화질), `?demo=1` (AI 플레이), `?hud=0` (HUD 숨김), `?touch=1|0` (터치 조작).

녹화 모드: `H` HUD 숨김, `O` 궤도 카메라, `T` 슬로모션.

## 한글화 노트

- **유지한 것**: 붓글씨 한자 글리프(斬 閃 格 氣 劍 등), 도장 이미지, 게임 타이틀 長風, 고전시 원문(敕勒歌 · 李白《俠客行》 · 《易水歌》), 한자 숫자 표기의 웨이브 배너. 무협 장르의 시각 언어이기 때문입니다.

- **폰트**: 한글 표시를 위해 Noto Serif KR을 추가했습니다(서리 SC/마산정·Cormorant Garamond는 원작 그대로, 한자 글리프와 라틴 이탤릭용).
